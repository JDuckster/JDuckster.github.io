Privacy Policy

Last updated: 1 November 2026

SuperMaxDuck ("the app") is a private automation project used only by its owner. This policy explains what Google user data the app accesses and how that data is handled.

Who uses the app

The app is used solely by its owner on their own computer. It is not offered to, and does not collect data from, any other person.

Data the app accesses

  • Google Calendar (read-only): event titles, times, locations, attendee counts and response status for upcoming events.
  • Gmail (read-only): sender, subject, date, snippet and, for selected messages, message text, to identify emails that may need attention.
  • Gmail (send): used only to send the daily summary email to the owner's own address.
  • Google Drive (metadata only): names, types and modification dates of recently changed files. File contents are not read.

How the data is used

The data is used only to produce a short daily summary for the owner. To write the summary, relevant excerpts are sent to an AI model provider (Anthropic's Claude API) over an encrypted connection. Anthropic processes this data under its commercial API terms.

Storage and retention

Google data is processed in memory while the summary is created and is not stored in a database. The only things kept on the owner's computer are the sign-in token, a log of each run (tool names and errors) and the date the last summary was sent. The summary itself is stored only as an email in the owner's own inbox.

Sharing

Google user data is not sold, shared with third parties for advertising, or transferred to anyone except as described above (the AI model provider, solely to generate the summary).

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local sign-in token also stops all access.
